# Unit Conversion API

## Description
A RESTful API built using ASP.NET Core to convert values between different units.

## Technologies Used
- C#
- ASP.NET Core Web API
- REST API
- .NET

## How to Run Locally
1. Clone or download this repository.
2. Open the solution file in Visual Studio.
3. Restore NuGet packages.
4. Build the solution.
5. Run the application using Visual Studio.

## Design Decisions
- Used ASP.NET Core Web API to expose HTTP endpoints for unit conversion.
- Organized the application into separate components to improve readability and maintainability.
- Kept the implementation simple and easy to extend.

## Trade-offs
- Focused on a straightforward implementation for clarity.
- Additional validation, error handling, and automated tests can be added to improve production readiness.
